隐私政策预览

内容核对日期：2026年10月28日

本页是依据当前功能准备的预览，尚未生效。经营主体、联系邮箱、处理所在地和保存期限确认后，将在这里公布正式政策及生效日期。

服务与信息用途

OneCrew Cloud帮助用户根据商品寻找创作者，查看公开内容依据与联系方式，并通过连接的Gmail编辑、确认和发送邮件。用户可以在Shopify后台使用店铺工作区，也可以登录网站、手动填写商品，使用独立个人工作区。

处理的信息

  • 店铺与商品：店铺标识、安装状态、成员授权信息，以及商品名称、说明、品牌和链接，用于认证、商品选择和搜索。当前仅申请Shopify商品读取权限，不通过商品接口读取客户或订单业务记录。
  • 账号与工作区：OneCrew登录身份、配对和安装绑定，用于识别用户、恢复访问，以及区分个人、店铺和成员的数据。
  • 平台会话：用户在独立浏览器内登录后保存的Cookie与站点资料，用于恢复YouTube、TikTok、Instagram会话。持久快照加密保存。
  • 登录表单：用户在Cloud网页填写的账号和密码会即时填入当前工作区对应平台的登录框。密码不进入任务、数据库、日志或模型，填入后清空；独立浏览器禁用新增密码保存。
  • 公开创作者资料：作者标识、主页、粉丝观察、公开内容、来源网址和公开联系方式，用于搜索、匹配与展示依据。
  • 搜索与推荐：商品输入、最低粉丝数、关键词、任务、模板、候选及推荐记录，用于完成搜索和重新查看结果。
  • 邮件：已连接邮箱标识、授权能力、收件人、主题、正文、发送批次和回执，用于用户确认的邮件操作与状态展示。
  • 运行与隐私请求：必要的运行错误、安装与隐私通知、请求处理记录，用于服务恢复、处理删除和访问请求。

Shopify隐私通知本身可能携带客户资料和订单引用；这些信息用于处理该通知。公开创作者资料和邮件信息也可能属于个人信息。

处理方式与服务提供方

商品输入及候选公开内容由服务端自托管的Qwen3-4B模型处理；显示的引用由程序从保存的来源复制。平台读取使用服务端独立浏览器和OpenCLI，用户无需安装桌面程序或扩展。

服务使用Shopify完成店铺认证和商品读取，使用OneCrew Access、Sync与API完成身份及邮箱连接，使用Google Gmail完成授权的邮件操作，使用Cloudflare Tunnel提供HTTPS访问，并访问用户选择的三个平台。相关服务根据其各自条款和政策处理信息。具体经营主体、处理所在地和适用的跨境安排仍待确认。

本页待经营主体确认的Google API使用说明：通过Google获得的信息仅用于用户授权的邮箱功能，不用于广告投放或训练通用人工智能模型；相关使用与传递应遵守Google API Services User Data Policy，包括其中的Limited Use要求。

用户控制

用户可选择商品、平台和粉丝条件，决定是否连接邮箱，并在实际发送前核对收件人和正文。断开某工作区的平台账号，会清理该工作区对应的平台站点资料和旧快照。平台仍可能要求重新登录或本人验证。

个人工作区和Shopify工作区相互独立；退出网站登录与删除工作区数据是不同操作。个人工作区的资料访问、更正和删除请求将由正式公布的隐私联系人核实处理，目前不提供整户自助删除入口。

Shopify卸载与删除

卸载会停用该店访问、移除离线会话并撤销对应Cloud邮箱安装。其他店铺及用户全局Gmail授权继续保留。为支持重装，研究记录可保留至Shopify后续的整店删除通知。

收到有效的shop/redact通知后，系统清理该店的任务、关键词、模板、推荐与证据、平台资料和快照、邮件工作区及安装信息。去重所需的不透明散列、通知主题、时间和序号可继续保留，原始通知正文不作为去重凭据保留。

客户数据请求与删除按同店客户标识处理相应隐私导出，不将公开创作者资料自动视作Shopify客户记录。店主可在“数据与隐私”查看适用请求。

保存期限、联系与生效

正式发布前，经营主体还需确认工作区、邮件记录、日志、去重凭据与备份的保存及清理周期，公布隐私请求邮箱、支持方式、生效日期和政策变更通知方式。当前预览不承诺未经确认的保存期限或响应时限。

公开数据的访问、更正和删除请求处理方式，将随正式联系方式一起公布。一般使用问题可先查看使用与支持。
