# 简化搜索与核验

2026-10-26。用户批准实施，只修改 onecrew_cloud。继续使用免费 4B Metal、8,192 窗口、现有关键词、原粉丝条件和默认 10 位目标。

## 当前实现

1. Instagram 内容搜索保留实际命中帖、正文和作者主页绑定。主页与粉丝核实后直接接入原内容回执和首次评分，不丢弃命中帖再寻找最近帖子。两条现有主页读取路径均已接入。
2. 初筛允许一条真实相关标题、分享、介绍、展示或产品清单。短帖保留全部原文片段；长材料继续使用现有关键词排序和上下文。附有优惠的实际商品介绍可以参与判断；只有广告或优惠时待核验。4B 选择身份依据和内容段落编号，代码复制原文、生成中文说明并映射原 95/85/70/40 分数。
3. 每个任务复用一个浏览器会话，结束或取消时保存并停止。保留店铺归属、外部请求排他、取消和恢复；继续使用现有单并发读取队列。
4. 搜索阶段不自动查联系页面。结果中的合格候选提供“查找联系方式”，每次只处理选定候选、最多两个页面，沿用原公开来源验证和 Library。不会重新评分或发送邮件。
5. 用户另行批准商品 vendor 同名规则：作者名称与非空 vendor 去除首尾空白、忽略大小写后完全同名，则身份与评分待核验，不推荐。旧商品快照缺少 vendor 时不猜测，明确粉丝超限仍排除。[批准范围](BRAND-ACCOUNT-APPROVAL.md)。
6. 用户另行批准私信下单规则：所选原文在同一句内出现 `DM … to order`（间隔不超过 80 字符）时，保守置为身份与评分待核验，不推荐。[批准范围](DIRECT-ORDER-APPROVAL.md)。

没有新增模型调用阶段、自动重试、平台权限、付费服务或公司 Git 修改。原有按需补读、已保存材料和粉丝预筛选继续复用。
