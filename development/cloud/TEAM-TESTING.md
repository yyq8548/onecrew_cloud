# 同事测试说明

入口：https://cloud.onecrewai.io/ 。当前为内部测试版本，默认英文，右上角可切换中文并记住选择；支持YouTube、TikTok、Instagram。

公开[使用说明](https://cloud.onecrewai.io/support)无需登录；[隐私政策预览](https://cloud.onecrewai.io/privacy)尚未正式生效。公司资料和审核账号缺项见[一次清单](SHOPIFY-REQUIRED-INPUTS.md)。

## 开始使用

1. 点击「Sign in / Create account（登录 / 注册 OneCrew）」，使用自己的账号完成登录和连接确认，返回工作台。没有Shopify店铺也可以使用；需要中文时在右上角选择「中文」。
2. 在「KOL 搜索」填写商品名称、用途和说明，选择平台及最低粉丝数，默认2000，不设最高限制。说明写清“商品是什么、用来做什么”即可，用于搜索词和用途匹配；品牌辅助识别官方账号，链接保留来源，两项选填。
3. 平台需要登录时，进入「平台账号」→「打开浏览器」，在平台页面选择账号密码登录。在窗口下方填写当前步骤的邮箱／用户名或密码，点「填入上方登录框」。看到“已填入”及输入栏清空后，按提示在上方平台页面点击Next、Log in或Continue；出现密码框后再填写密码。验证码、扫码及Google账号选择在原站完成。进入动态首页或本人主页后点「保存并检查」。搜索正在运行时，先点击「停止搜索，启用登录」；已找到的结果保留。Google登录完成不一定表示已进入对应平台。
4. 看到已登录后回到搜索页，点击「开始寻找」。页面显示阶段与数量，结果自动保存；目标共十位，不同频道分别计数。来源不足或条件较窄时可能少于十位。
5. 搜索期间直接在推荐表查看已找到的KOL、粉丝数、匹配依据和「查看原文」，数量增加时表格自动更新，并按粉丝数从高到低排列。同类商品、其他品牌同类商品或直接配套都可以推荐。联系方式栏始终提供已有的平台主页；公开邮箱不足时，可直接打开YouTube、TikTok或Instagram主页，也可使用其他公开入口或点击「补查联系方式」。

账号和密码自动定位填入，无须在远程画面逐字输入；密码在本次填入结束后清空，Cloud不保存密码。其他输入可展开「粘贴验证码或其他文字」，先点远程输入框，再填写并点击「粘贴到浏览器」。密码和验证码只在自己的登录窗口填写，不发给同事或聊天。

「最近任务」可重开结果；可保存条件模板。登录窗口点击「返回工作台」会先保存会话再退出；「保存并检查」在当前浏览器完成检查，再加密保存一次。看到检查或保存中请等它返回后再切换平台。登录信息会加密保存，通常无须每次重新登录，平台要求重新验证时再打开窗口。个人工作区与Shopify店铺工作区独立，账号和结果不会自动共用。

## 测试邮件

在「邮件」连接自己的Gmail。可从推荐表勾选有邮箱的联系人后点击写邮件，也可在邮件页添加已保存联系人或每行填写一个邮箱。

先给自己的邮箱测试：核对发件邮箱、收件人、主题和正文，进入预览后再确认。批量会逐封发送，查看批次进度及发送记录；未知发送结果不要直接新建同样批次重复发送。给真实KOL发信前，先取得本次联系的业务授权；测试推荐不等于授权发信。

## Shopify同事

从自己的测试店铺后台「应用」进入OneCrew Cloud，在工作台选择同步商品或手动填写。已有主测试店铺可供经负责人安排的测试；**不要重新安装 `onecrew-cloud-privacy-test.myshopify.com`**，该店正在等待真实隐私删除通知。

## 遇到问题

| 情况 | 操作 |
| --- | --- |
| 平台显示需要登录 | 确认在远程窗口内进入了平台主页，再保存检查；保留错误文字，勿反复断开重连 |
| 找不到十位 | 先核对商品用途、平台和粉丝范围；保留本次任务编号反馈，不把不符合者凑进结果 |
| 没有公开邮箱 | 使用其他公开入口或补查；不要猜测邮箱 |
| 网站打不开或运行中断 | 联系本项目负责人核对Mac、Docker、模型与网络；服务目前依赖这台Mac开机联网 |
| 邮件失败或结果未知 | 查看批次记录并反馈，避免重复确认发送 |

反馈格式：页面／操作、期望结果、实际结果或错误文字、发生时间、任务编号。截图遮住自己的邮箱和账号；不要发送密码、验证码、Cookie或授权链接。

当前匹配是公开材料初筛，粉丝数可能为近似观察，平台验证与限流会影响结果。最新速度记录仅供内部参考，不承诺固定耗时。其他同事从零注册的独立验收仍待完成。
