# 本地 4B 输入精简方案

状态：2026-10-25 用户选择精简输入，并明确批准“验证一下试试”。模型窗口继续保持 8,192，扩大窗口的方案未采用。

两份原完整请求约 9,225、22,165 token，超过既有窗口。当前 v16 复用原评分、关键词和原审核，只修改 onecrew_cloud 的模型输入：

- 完整候选材料、网页正文、原引用、材料哈希和审核仍保存在原数据库及证据结构中。
- 4B 只接收商品信息、作者基本资料、关键词命中的最多五个原生内容段落及每段前后最多 120 个字符。没有关键词命中时保留各原生来源开头，允许证据不足；简介最多取 400 个字符。
- 第三方网页仍可保存和查看，评分的可选段落来自作者原生内容，不把第三方网页广告当作作者依据。
- 4B 继续输出身份、关系与段落编号；代码从原材料复制原文，保留粉丝判断、95/85/70/40 映射、已批准促销规则和原审核。原纠正上限不变，没有新增模型调用。
- 商品在评分请求中保留一份，移除重复附带的完整商品快照。规则版本及所选材料参与原缓存身份。
- 免费 4B、Metal、单并发、非思考模式和 Linux 配置保持原样，不购买服务、不测试 8B。

真实小样本已证明窗口超限可以通过输入精简消除；护肤内容与防晒商品的宽泛关联仍有漏判，不能宣称评分质量全部通过。完整任务和验证记录见[基础流程](../BASIC-WORKFLOW.md)。
