状态：用户已批准简化评分提示词、适当降低评分标准、[一次分类与代码评分](COMPACT-CLASSIFICATION-APPROVAL.md)、[关键词复用、段落编号和代码复制原文](QUOTED-REASON-APPROVAL.md)、[合作或优惠摘录待核验规则](PROMOTIONAL-EXCERPT-APPROVAL.md)及[v16 输入精简](model/CONTEXT-WINDOW-APPROVAL.md)。当前为 paragraph classification v16，原分数映射保留，代码生成中文等级说明和真实引用，并将命中两个批准表达的正向评分置为待核验。仅使用免费 4B；当前真实样本、任务和 Linux 检查看[基础流程](BASIC-WORKFLOW.md)。关键词已完成 50 份输入测量，人工评分质量及评分 P95 仍未完成。

## 当前简化标准

真实账号的一条已发布或分享的内容，与商品品类或明确使用场景相关，即可支持初步入选。接受视频标题加说明、产品清单、分享或转载；不要求实际使用效果、同一商家品牌、原创、合作经历、字幕或多条内容。账号名称、搜索词、偶然插入的广告或第三方商品页面不能单独证明内容相关。

保留原评分数值与结果格式：95 为直接介绍同类商品且有具体内容；85 为内容品类明确相关；70 为有证据的使用场景关联并说明联系；40 为有证据的较弱匹配；资料不足时暂不评分。没有设置额外的 85 分入选门槛。粉丝范围仍由原代码判断；来源归属、证据编号、完整材料和原审核不变。评分理由使用简短中文，不能声称未观察到的效果、专业能力或商业表现。

此调整仅用于 Cloud 简化任务，旧格式任务与相邻 Lite 仓库不变。模型仍为已批准的免费 4B；本地模型输出通过格式审核不代表内容或引用语义已经通过人工验收。

Cloud 模型输出段落编号、创作者身份和内容关系；代码复制原文、生成中文理由、将关系映射到上述等级，再生成原入选、质量和商品条件字段。仅在条件与固定简化任务完全一致时采用这一转换，旧格式任务保持原流程。模型无法添加筛选条件，证据仍由原引用还原和审核检查；身份不明、只有夹带广告或证据不足时保持待核验。

## 实测依据

当前简化入口已取消长文本规划，关键词单平台约 26 秒、四平台约 58 秒。评分仍调用原 Lite 评分规则。

使用此前保存的真实 YouTube 护肤内容和明确的本地防晒商品文字测试，评分规则为 10,000 字节、候选输入为 4,455 字节。模型日志显示输入处理约 239.57 秒才完成 2,048 token，进度 58%，尚未生成评分。当前电脑使用原 Qwen3-8B Q4_K_M、CPU 推理；没有 Shopify 商品或完整业务验收结论。

该次请求最终在五分钟超时后退出，未得到评分结果，模型容器已停止。证据为 `.scratch/cloud-product-score.log` 与 `.scratch/cloud-product-score-server.log`。

8B 测试的短规则为 1,826 字节，候选输入保留完整原证据；约 237 秒处理完 2,048 token（96%），五分钟时仍未完成评分。4B 使用 1,936 字节规则仍把原生粉丝区间高于上限的候选判为符合，原审核拒绝，没有评分回执写入原任务。用户随后批准将粉丝条件交给代码，模型仅判断 KOL 身份、商品相关性与质量；详见[粉丝条件审批](DETERMINISTIC-FOLLOWERS-APPROVAL.md)及[验证记录](model/README.md)。

## 拟修改内容

仅修改 `onecrew_cloud` 中以下部分：

1. `onecrew_lite-app/src/cloud/campaign-scoring.ts`：新增简化任务专用的短评分规则，只表达商品相关性、KOL 身份、粉丝范围、评分等级，以及真实证据引用和缺失证据处理。等级含义采用上述用户要求放宽后的标准。输入保留商品文字和原候选材料，不截断材料来缩短请求。
2. `onecrew_lite-app/src/discovery/semantic-match.ts` 与 `runtime.ts`：增加由 Cloud 入口传入评分规则的明确参数。继续使用原证据编号、结果 schema、引用还原、作者归属、条件版本、审核回执及待核验判定。新规则具有独立版本标识，避免复用旧规则的评分缓存。
3. `onecrew_lite-app/src/cloud/campaign-service.ts`：仅为新的简化任务选择上述规则。已有其他格式任务保留原评分流程；关键词、搜索执行器和结果展示继续复用当前实现。
4. 更新相关检查和模型性能脚本，使用同一份真实保存材料比较实际耗时、评分与引用。正式质量验收仍需要约定的人工样本及批量延迟数据。

## 审批边界

这项调整已经按用户“方案调整先审批”的要求取得批准。当前已经完成的商品相关性必需条件修复继续有效。

短规则验证时保持原免费模型及运行配置；后续模型更换遵守单独批准的范围。不购买服务，不修改 Lite、Access 或 Sync，不增加邮件功能或浏览器权限。评分速度以实际测试为准，单次检查不代表完整 KOL 搜索或上架验收通过。
