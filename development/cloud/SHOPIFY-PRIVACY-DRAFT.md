## 可发布正文草稿

### 我们是谁

OneCrew Cloud由[经营主体]提供，用于根据商品寻找相关创作者、查看公开内容依据及联系方式，并通过用户连接的Gmail编辑和发送邮件。隐私问题可通过[隐私联系邮箱]联系我们。本政策自[日期]生效。

### 我们处理哪些信息

| 信息 | 来源与用途 |
| --- | --- |
| 店铺与商品 | Shopify店铺域名、安装状态、成员授权信息及商品标题、说明、品牌和链接，用于认证、选择商品和建立搜索条件 |
| OneCrew账号与工作区 | 登录身份、个人或店铺成员绑定、配对与安装记录，用于识别用户和隔离其工作区 |
| 平台会话 | 用户在独立远程浏览器内登录后保存的浏览器资料、Cookie及站点存储，用于恢复同一工作区的平台访问；持久快照加密保存 |
| 登录表单 | 用户自愿在Cloud网页填写的账号和密码，经当前工作区的登录接口即时填入对应平台；密码不进入任务、数据库、日志或模型，填入后清空。独立浏览器禁用新增密码保存 |
| 公开创作者资料 | 平台作者标识、主页、粉丝观察、公开内容原文、来源网址及公开联系入口，用于搜索、筛选、核实并展示推荐依据 |
| 搜索与推荐 | 商品输入、粉丝条件、关键词、任务、模板、候选、匹配结论和保存的来源，用于完成研究及重开结果 |
| 邮件 | 已连接邮箱标识、授权能力、用户填写的收件人／主题／正文、发送批次和Gmail回读记录，用于确认、发送、展示状态和处理重复请求 |
| 运行与隐私请求 | 运行状态、失败记录、Webhook及隐私请求与处理记录，用于运维、恢复、验证通知和处理数据权利请求 |

应用当前仅请求Shopify的`read_products`，不通过Admin API读取客户或订单业务记录。Shopify隐私通知本身仍可能包含客户信息与订单引用，我们会按通知目的处理这些信息。公开创作者资料、店主身份和邮件信息也可能属于个人信息。

### 如何处理及提供信息

商品说明和候选公开内容由服务端自托管的Qwen3-4B模型进行类别及身份判断；显示的引用由程序从保存的来源复制。平台读取使用服务端独立浏览器和OpenCLI。用户通过网页使用，服务主机位于[确认后的处理所在地]。

服务使用Shopify完成店铺认证和商品读取，使用OneCrew Access／Sync／API完成账号及邮箱授权，使用Google Gmail完成用户确认的发送与回读，使用Cloudflare Tunnel传输公网HTTPS流量，并访问用户选定的YouTube、TikTok和Instagram。向各服务传递其完成相应功能所需的数据；收件人会收到用户确认的邮件内容。相关服务还适用各自的隐私政策，主体应在发布版列明实际服务提供方与必要跨境说明。

### 控制、保存与删除

用户可选择平台、商品和粉丝条件，决定是否连接邮箱，并在发送前检查收件人与正文。断开某工作区的平台连接会清除对应浏览器站点数据与旧快照。平台自身可能要求重新登录或验证。

卸载Shopify应用会停用该店访问、移除其离线会话并撤销对应Cloud邮箱安装；不会因此撤销用户全局Gmail授权或删除另一店铺数据。任务和推荐在等待Shopify整店删除通知期间可保留，以支持重装恢复。收到有效`shop/redact`后，系统清理该店的浏览器及快照、账号证据库、Library、任务和关键词、模板、邮件工作区数据，以及安装与原始隐私通知记录。系统保留不含原始请求body或明文店铺域名的主题、时间、序号与不透明散列等去重凭据。

客户数据请求会生成受限的加密导出，包含该请求提供的信息；当前未存储客户或订单业务记录。客户删除按同店客户标识清理相应隐私导出，不将公开创作者资料自动视作Shopify客户记录。实际保存期限与去重凭据清理期限为[待确认期限]；备份删除周期为[待确认周期]，必须与部署安排一致。

独立网页用户和创作者可向[隐私邮箱]申请访问、更正或删除与自己有关的信息。我们会核实请求身份，并按适用要求和[确认后的处理程序]处理；公开资料的来源平台更正可一并提供。个人工作区的删除程序与负责人需在发布前确定。

### 保护与政策变更

我们对身份和工作区权限进行验证，持久保存的授权会话、平台快照与隐私导出使用加密及受限文件访问。公开隐私政策不得承诺绝对安全或未经验证的认证资格。政策更新将通过[公开政策地址及通知方式]发布；联系信息为[支持及隐私联系人]。
