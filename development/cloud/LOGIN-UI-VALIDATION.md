# 本机平台登录界面验证

2026-10-26，仅修改 onecrew_cloud。

- Cloud 登录组件改为占满应用窗口，提供原始尺寸与适应窗口切换，连接后聚焦远程画面。Escape 保留给平台页面使用，通过“保存并关闭”结束登录。
- 本机独立验证页同步压缩顶部区域，增加全屏和尺寸切换。保存按钮在远程连接成功后启用，旧连接的断开事件不会覆盖新连接或保存结果。
- 原生前端类型检查和 Cloud 构建通过。真实验证页连接 X 成功，原始尺寸切换和进入全屏均通过浏览器操作检查。样式扫描未报告问题，但扫描器缺少 HTML 解析模块，其结果不代表完整视觉验收。
- X 登录仍未通过。对可见 Use password 按钮执行真实点击，确认产生 `jf.x.com/onboarding/web/actions/begin_login` 请求。响应 HTTP 200，正文明确包含 `We’ve temporarily limited your login. Please try again later.`；页面没有显示这条错误，因此表现为点击后仍停留在账号确认页。
- 收到明确限制后停止登录重试。X 未返回限制原因、作用范围或解除时间，不能据此认定账号、IP 或自动化检测中的某一项触发限制。界面放大和出现密码框不代表登录恢复。Cloud 无法解除平台侧限制，真实登录验收仍待限制解除后完成。
- YouTube、TikTok、Instagram 的已有加密会话保留。未修改认证规则、浏览器权限、公司仓库或 Lite。

本机验证页与诊断脚本位于受忽略的 `.scratch`，包含私有入口和账号数据，不提交 Git。
