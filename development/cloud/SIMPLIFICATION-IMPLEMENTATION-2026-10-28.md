# 搜索与运行开销优化

用户批准按批量邮件与代码简化分析实施。只修改 onecrew_cloud，不改变匹配标准、粉丝条件、目标十位和公开联系补查范围，不购买服务，不修改公司源码或配置。

## 实现范围

- 任务结束后停止轮询；离开搜索页面后，运行任务只查询列表以更新账号占用状态，不再查询详情。返回搜索时刷新。原编辑状态、取消和过期响应处理保留。
- 个人工作区不再请求始终为空的 Shopify 商品列表。
- 阶段没有变化时不写数据库；联系补查复用调度器已经完成的 Library 发布。
- YouTube 复用已有独立读取通道，在模型判断期间读取另一作者的视频。保留目标余量、平台串行读取、同作者和同网址排除，以及材料版本提交检查。尚无原生作者编号时，同名来源也排除并行读取。
- 固定 Cloud 浏览器中的 OpenCLI reader 复用本次运行已核实的 profile；命令失败、浏览器重开或明确要求检查时重新探测。实际浏览器运行、取消、归属和命令失败检查保留。
- HTTP 请求复用入口已验证的 Shopify 身份，仍交换并核对远端成员权限；个人请求不重复执行没有异步间隔的安装检查。
- 合并同进程内重复的浏览器参数和账号校验，进程入口与结果归属检查保留。
- 代理实现和 Excel 编码器改为使用时加载；商品英文关键词处理独立于 MCP 工具目录加载，规则保持相同。
