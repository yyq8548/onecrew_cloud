## 已处理并保留证据的问题

| 问题 | 当前处理与边界 |
| --- | --- |
| 评分完整材料超过 8,192 上下文 | 用户批准将完整材料留库，只向模型发送相关作者段落及上下文。两份原超长材料终版输入降到 1,002、1,322 token 并通过原审核；保持 4B 与 8,192，未扩大窗口。语义质量仍需单独验证。 |
| 关键词用完后误启动长扩词请求 | 旧执行器忽略 `automatic_query_expansion: false`。已在验证店铺归属和任务版本后提前返回，不发平台或模型请求。真实任务恢复后正常结束，调用计数保持 66，结果重开一致；默认目标未找满时保存实际结果。 |
| 免费模型 CPU 规划/评分慢 | 用户批准取消长规划、改为固定输入与短关键词，使用同一免费 4B；Mac ARM Metal 已验证。Linux CPU 配置保留，不能宣称 CPU 性能门槛通过。8B 对比没有稳定改善，用户已禁止再测试 8B。 |
| 模型误判粉丝范围 | 复用 `discoveryScale` 和原生数/舍入区间，由代码预筛选与合并；明确超限不调用模型。跨界或缺失仍待核验，不能把超限样本混入模型评分一致性比较。 |
| 自由理由补写商品名、摘录改写或抄错优惠码 | 当前模型只返回段落编号，代码复制原文和生成等级说明；保留完整材料、归属、版本和原审核。水杯商品清单及护肤标题按批准标准可使用。 |
| 同一视频选到其他商品广告或厨具段落 | 使用现有关键词限制可选摘录，保留标题/来源开头及完整上下文；同一请求末尾明确本次商品目标。当前小样本通过，不能当成全面语义正确性保证。 |
| HTTP 响应外层不精确小数导致整包解析失败 | 外层使用现有 lossless-json 保留额外数值，业务 JSON 与用量继续严格验证。原偶发故障的具体字段未捕获，后续短请求没有精确复现，不能声称已找到原字段。见 [客户端审批](../cloud/MODEL-ENVELOPE-APPROVAL.md)。 |
| Docker 中 Chromium sandbox namespace 被阻止 | 已批准仅浏览器测试容器的受限 seccomp；保留 Chromium sandbox。不要改为 privileged 或 `--no-sandbox`。 |
| CDP 清理后残留 Google/YouTube 域 Cookie | 已批准在原允许域与指定会话内使用扩展已有 `chrome.cookies.remove` 清理残留，并清理旧加密快照；实际存储及旧快照升级组件验证通过，真实登录账号仍待验收。 |
